# 360 Graphics TZ — website

Multi-page animated website for 360 Graphics, a graphic design studio in Dar es Salaam, Tanzania.

Pages: Home, Services, Work, About, Contact. Plain HTML, CSS and JavaScript (GSAP, ScrollTrigger, Lenis), so it runs on GitHub Pages with no build step.

To change the text, edit the `.html` files. To add work, put an image in `img/work/` and add a tile in `work.html`.
